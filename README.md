# Leviathan Ocean
This is a minecraft datapack that makes the oceans generate much deeper than usual.

See full description on [Modrinth](https://modrinth.com/datapack/levio).

## Version
The `main` branch is the datapack for version 1.21.11 - 26.2.
<br>
If you need another version, change to the branch corresponding to that version (e.g. `ver/26.3`).
<br>
If the version you want doesn't have a branch for, it is not supported.
## Download
You can download this datapack on Modrinth, or from this github repository.
<br>
If you prefer to download from the repo, Click on the green "Code" button, then "Download ZIP".
